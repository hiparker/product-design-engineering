# 视觉参数与校准方法

以下数值是从空白开始设计 Web 界面时的试排起点，既有产品优先沿用现有样式，用当前项目的文字、内容密度和设备校准，选定后复用同一组样式

## 排版和留白

| 项目 | 可试的起点 | 在实际画面里看什么 |
| --- | --- | --- |
| 工作台 | 页标题 24–32 px，行内正文 14–16 px，辅助文字 12–14 px | 异常原因与关键单位在默认缩放下仍容易读，同一条记录最多只需一次明显的字级变化 |
| 产品页 | 桌面首屏标题 40–64 px，手机 30–40 px，正文 16–18 px | 连续两三行标题保持完整语义，首屏还能看到用户需要判断的产品细节 |
| 中文长文 | 正文从 16–18 px、约 1.65 倍行高试起，桌面文本列每行约 30–40 个汉字 | 连读三段观察回行是否费力，手机自然换行，英文标识或链接能在列内断开 |
| 间距 | 可从 4、8、12、16、24、32、48 px 选少量级别 | 试用 4 px 连起字段名与补充说明、16 px 分开字段、32 px 分开章节，遮住分割线后仍看得出分组 |
| 表格 | 桌面行高先试 40–48 px，金额对齐末端，为同列数字启用 tabular-nums | 连续扫描十行能沿列比较，看得到负号与币种，换成两行标题后行内操作仍能对齐 |

窄屏容不下标题时先扩大文字的可用宽度，移走并排的次要操作，再调字号，中文标题里的专有名词、数字和单位尽量保持在一起，正文避免手动断行

## 从内容选配色和材质

- **先确定中性色的用途**　分别试画页面底、内容表面、主文字、次文字与分隔线，检查次文字在真实背景上的可读性，必要时加深文字
- **再选品牌强调色**　没有指定色时可从产品素材取色，例如陶器目录可从釉色取深青用于选中规格，底色贴近摄影背景，让器物轮廓保持完整；釉色本身过浅时另选较深的交互色
- **允许两种信息叠加**　被选中的订单行可用淡底与勾选框，逾期字段再用警示色和「逾期 2 天」文字，键盘焦点用独立轮廓，以覆盖选中且逾期的情况
- **颜色数量取决于编码需要**　有多条趋势线时配合直接标签、线型或点型区分系列，反复用同一颜色指代同一对象；只有一条时间序列时，弱化网格线，将最近值与单位贴近数据
- **圆角和投影跟随边界**　先定控件与容器两种半径，例如控件 8 px、预览容器 16 px，嵌套时观察内外弧间距；常驻面板可只靠细边线，跨层菜单出现时再加投影
- **已有深色模式时做成对检查**　在深色表面单独校准文字、边界、焦点和图表线，重新检查图片边缘与透明背景，避免只反转底色导致状态消失

## 控制动效与中断

| 变化 | 可试的起点 | 使用条件 |
| --- | --- | --- |
| 按下、选中、切换 | 颜色或透明度过渡约 100–160 ms | 输入即时响应，连续点选时最后一次选择立即生效 |
| 展开详情、抽屉进入 | 约 180–240 ms，短距离位移后减速 | 起点和终点有明确的空间关系，退出时用户能找回原先位置 |
| 对照、产品导览 | 用点击、方向键或滚动推进，每一步均可静止阅读 | 用户能跳到任一步，切换过程中再次操作能中断，手机用点按也能理解全过程 |

若动作频繁、延迟已经可感知，直接更新内容即可，启用减少动态效果偏好时，移除大幅位移、视差与自动推进，步骤名称、选中标识和操作结果继续显示

## 将视觉参数组织成一致的主题

- **建立语义映射**　把页面底、内容表面、正文、次文字、边界、品牌操作、成功、警告、错误和焦点分别命名，同一用途在各页面复用，状态色配合文字说明
- **一起设计控件状态**　用同一个按钮、输入框和选择器检查默认、悬浮、按下、聚焦、禁用、加载和错误状态，品牌主色调整后检查文字对比及细边界
- **让密度成组变化**　紧凑与常规布局同步调整行高、内边距、控件高度和组间距离，表格里的动作仍可触达，关键文字保持可读
- **统一动作强弱**　主操作用实心或其他清晰强调，次要动作弱化表面，危险动作明确表达影响，选中态、键盘焦点与业务状态叠加时各自可辨
- **检查主题覆盖面**　明暗模式下验证输入框、菜单、弹层、校验信息和滚动区域，按当前组件库版本使用主题变量与配置机制
