# 前端实现与验收

用于把已确定的界面变成可用实现，或检查现有界面的具体问题，按当前改动选择相关部分，沿用项目已有构建、组件、测试与发布方式

## 从现有实现确定边界

- 读取项目说明、依赖与锁定版本，确认框架、路由、数据请求、主题、表单和测试约定，已有组件先检查实际用法与覆盖的状态
- 设计规则优先归入已有语义变量和组件，只有业务含义、状态或交互确实不同才增加变体，页面局部例外写清用途
- 全新页面可以比较少量视觉方向，局部修正直接处理问题，样式库和检索结果作为候选，使用前检查内容、平台和任务是否相符
- 实现涉及特定 API 时核对对应版本的官方文档，保留现有兼容范围，避免为局部效果引入整套新依赖

## 给状态指定归属

| 状态 | 推荐归属 | 需要明确的行为 |
| --- | --- | --- |
| 需要分享或返回的筛选、排序、页码 | 路由或 URL 中的非敏感参数 | 刷新、前进和后退恢复合理上下文 |
| 尚未提交的输入、展开项、指针交互 | 当前页面或组件 | 切换与关闭时保留、提交或放弃的规则 |
| 业务记录、权限、任务进度 | 服务端事实及其前端缓存 | 何时刷新、何时过期、错误与冲突如何表达 |
| 主题、密度等用户偏好 | 项目约定的偏好存储 | 默认值、覆盖范围与跨设备同步能力 |

- URL 不放凭证、敏感搜索内容或整份表单草稿，记录标识仍由服务端校验权限
- 请求结果匹配当前对象、查询条件和请求批次，旧响应不得覆盖新状态，取消读取与取消已提交业务操作遵循各自语义
- 乐观更新适合失败代价低且可恢复的动作，写清待确认状态、回退与并发处理，权限审批和外部副作用按服务端确认表达结果
- 切换对象或退出页面时清理监听、计时器和订阅，避免旧对象的副作用继续更新当前页面
- 服务端渲染与客户端首次渲染使用一致的初始值，时间、区域和浏览器偏好在明确阶段处理，避免通过隐藏警告掩盖不一致

复杂表单、表格与浮层的行为读[后台布局与组件决策](component-patterns.md)，写入与异步任务的结果语义读[服务端架构决策](service-architecture.md)

## 输入、操作与内容的可访问性

- 动作用按钮，跳转用链接，优先使用原生控件及其键盘行为，自定义控件再补齐语义、键盘与焦点，避免给原生按钮重复触发逻辑
- 字段标签与控件关联，图标按钮有可访问名称，说明性图片有替代文本，装饰图像不干扰读取，动态反馈按重要性播报
- 键盘路径与阅读顺序对应，焦点清楚且不被固定区域遮挡，密集界面保证相邻点击区域不会重叠，触屏实测误触与可达性
- 输入类型、自动填充与键盘提示跟随数据含义，电话号码和有前导零的编号按字符串处理，允许正常粘贴和密码管理器工作
- 中文输入法组合过程中避免触发提交或用中间拼音发起搜索，组合结束后处理确定输入，验证 Enter 确认候选与表单提交的边界
- 拖动控件提供可点按或键盘完成的等价方式，中断、失去指针捕获与窗口切换后清理拖动状态，下一次操作可正常开始
- 主题检查包含正文、次要文字、选中、错误与焦点的实际组合，按项目适用的可访问性标准测量对比度，保留文字缩放与减少动态效果的能力

## 真实内容与布局韧性

- 用空内容、最长名称、大数值、连续长标识和项目支持的语言检查布局，截断时仍能获取影响判断的完整内容
- 优先修复容器尺寸、换行与子项收缩，避免用整页隐藏横向溢出来遮住按钮或字段，表格横滚限定在数据区域
- 浮层检查祖先裁切、层叠、滚动与焦点，按项目支持能力选用顶层弹层或挂载方式，挂载位置改变后仍验证主题和标签关系
- 日期区分业务日期与具体时刻，金额明确币种和精度，展示遵循约定的区域与时区，前后端保持一致的数据语义
- 图表从比较、趋势或分布任务选择形式，明确单位、时间范围、统计口径和缺失值，颜色之外提供标签，关键读数不依赖悬浮才能访问

## 用测量选择性能改动

- 先区分首屏等待、输入迟滞、滚动卡顿与内存持续增长，记录设备、网络、数据规模及复现路径，再检查资源瀑布、渲染或调用过程
- 首屏关键内容及时加载，非关键资源按需加载，图片与嵌入内容预留尺寸，字体加载检查替代字体切换造成的布局变化
- 输入反馈保持及时，昂贵查询和计算单独调度，页面卡顿时先定位长任务、重复渲染或读写布局交错，再考虑缓存、拆分或后台计算
- 数据规模和实际渲染成本决定分页或虚拟化，采用虚拟列表后验证动态行高、焦点、辅助技术、页内查找与打印需求，保留合适的替代访问方式
- 动效优先使用成本可控的属性，限制大面积模糊和持续重绘，允许中断并响应减少动态效果，完成状态无需等动画结束才能操作
- 在可比较条件下记录前后结果，实验环境分数和真实用户体验分别表述，优化后复核主路径和相关交互

## 按风险形成验收证据

| 改动 | 优先验证 | 交付记录 |
| --- | --- | --- |
| 排版、颜色与组件样式 | 实际截图、窄屏、缩放、最长内容、相关主题 | 看过的尺寸、状态和剩余视觉问题 |
| 输入、选择与提交 | 键盘、输入法、校验失败、重复操作、离开再返回 | 输入条件与可观察结果 |
| 请求与页面状态 | 慢响应、失败、乱序、版本冲突与上下文恢复 | 请求场景和界面结果是否一致 |
| 性能优化 | 同一路径、相近设备和数据下的前后测量 | 指标、环境与功能回归结果 |
