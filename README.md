把用户问题转化为有价值、易使用、可可靠交付的产品

## 界面演示

下载仓库后，在浏览器中打开 [assets/interface-lab.html](assets/interface-lab.html)，可离线体验视觉插件、控件、配色和页面模式

演示使用模拟数据与本地交互，实际项目的持久化、权限和异步任务需要对应的服务端实现

## 设计原则

- 从已有证据、用户任务和项目约束出发
- 按页面用途安排内容层级与视觉表达
- 保持业务状态、界面反馈和接口结果一致
- 以实际渲染、操作路径与相关测试支持验收结论
- 按问题规模选择方法，已有品牌、技术栈与组件体系优先复用
